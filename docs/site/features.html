quickshell's features, one by one

every type in quickshell 0.3.2's public docs, grouped by module, with what crabshell has today. each square is one type. select a square to find it in the list.

green check: built and working
yellow bar: partly built. the note says what's there
empty box: not built yet. the note gives its phase
red cross: tried, and it failed. nothing has so far
gray dash: qml plumbing that plain rust already covers

a type counts as built when crabshell has something that does its job, under its own name. the notes say which.

crabshell is mit or apache-2.0 licensed. its colors are rime and rime frost, plus an orange made to match.
