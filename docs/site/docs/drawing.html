crabshell Docs

Drawing and images

Styles cover boxes and text. For a ring, a graph or a picture there are three widgets: Canvas, Icon and Image.

Canvas

Canvas::new(|pen| ...) is a box your closure draws in, sized by its style. 

const RING: Style = Style::new().width(96.0).height(96.0);

let ring = Canvas::new(move |pen| {
  let size = pen.size();
  let center = Point::new(size.width / 2.0, size.height / 2.0);
  let radius = size.width.min(size.height) / 2.0 - 4.0;

  // The dim full circle, then the part that is charged.
  pen.stroke(&Path::circle(center, radius), &Stroke::new(8.0, TRACK));
  let percent = battery.get();
  pen.stroke(
    &Path::new().arc(center, radius, -90.0, percent * 3.6),
    &Stroke::new(8.0, ACCENT).cap(Cap::Round),
  );
})
.style(RING);

The paint closure is a binding. It runs once the canvas has a size, and again when the size or a signal it read changes. Each run replaces the whole drawing, and only the canvas's box repaints. Coordinates are logical pixels from the canvas's top-left corner.

The pen

Method What it does
pen.size() The canvas's size, as a Size with width and height.
pen.fill(&path, paint) Fills the path.
pen.stroke(&path, &stroke) Draws a line along the path.

A paint is a Color or a Gradient, and a gradient is laid over the whole canvas and dithered, as a style's is.

Paths

let line = Path::new()
  .move_to(Point::new(0.0, 20.0))
  .line_to(Point::new(40.0, 8.0))
  .quad_to(Point::new(60.0, 0.0), Point::new(80.0, 20.0))
  .cubic_to(Point::new(90.0, 30.0), Point::new(110.0, 30.0), Point::new(120.0, 20.0));
Method What it adds
move_to(point) A new starting point.
line_to(point) A straight line.
quad_to(control, to) A curve with one control point.
cubic_to(first, second, to) A curve with two control points.
arc(center, radius, start, sweep) Part of a circle. Angles are in degrees, clockwise from 3 o'clock. A negative sweep runs counterclockwise.
close() A line back to the start.

Path::rect(rect), Path::rounded_rect(rect, radius), Path::circle(center, radius) and Path::ellipse(center, radius_x, radius_y) build whole shapes.

Strokes

Stroke::new(2.0, ACCENT).join(Join::Round).cap(Cap::Round)
Stroke::new(1.0, GRID_LINE).dash(&[3.0, 3.0], 0.0)

Stroke::new(width, paint) takes cap(Cap::Butt | Round | Square), join(Join::Miter | Round | Bevel) and dash(pattern, offset). Paths and strokes are plain data, so build the ones that never change outside the closure.

A graph

The dashboard example's CPU graph has dashed guide lines, a filled area and a line over it. cpu is a signal holding the last minute's samples, each from 0 to 1. 

let graph = Canvas::new(move |pen| {
  let size = pen.size();
  let grid = Stroke::new(1.0, GRID_LINE).dash(&[3.0, 3.0], 0.0);
  for quarter in 1..4 {
    let y = (size.height * quarter as f32 / 4.0).round() + 0.5;
    let line = Path::new().move_to(Point::new(0.0, y)).line_to(Point::new(size.width, y));
    pen.stroke(&line, &grid);
  }

  let points: Vec<Point> = cpu.with(|samples| {
    let step = size.width / (samples.len().max(2) - 1) as f32;
    samples
      .iter()
      .enumerate()
      .map(|(at, usage)| Point::new(at as f32 * step, 1.0 + (1.0 - usage) * (size.height - 2.0)))
      .collect()
  });
  let (Some(first), Some(last)) = (points.first(), points.last()) else {
    return;
  };
  let line = points[1..].iter().fold(Path::new().move_to(*first), |path, point| path.line_to(*point));
  let area = line
    .clone()
    .line_to(Point::new(last.x, size.height))
    .line_to(Point::new(first.x, size.height))
    .close();
  pen.fill(&area, GRAPH_FILL);
  pen.stroke(&line, &Stroke::new(2.0, ACCENT).join(Join::Round).cap(Cap::Round));
})
.style(GRAPH);

A horizontal line one pixel wide is sharpest when its y ends in .5. A paint closure that panics is logged as <path>/Canvas.paint and disabled, and the last drawing stays.

Icons

Icon::new(source) takes one of three things.

Icon::new("firefox")                               // a name from the icon theme
Icon::new(std::path::Path::new("/opt/app/icon.svg"))   // an SVG or PNG file
Icon::new(move || IconSource::Name(entry.get().icon))  // a closure returning an IconSource

A &str is always a theme name. For a file, pass a std::path::Path or a PathBuf, since the prelude's own Path is the canvas one. A desktop entry's icon can be either, so check it. 

let icon = move || {
  let icon = entry.get().icon;
  if icon.starts_with('/') { IconSource::File(icon.into()) } else { IconSource::Name(icon) }
};
Icon::new(icon).size(20)

Names follow the freedesktop icon theme rules, and the default theme is the one GTK apps use, or hicolor when GTK names none. cx.set_icon_theme in the root closure picks another. An icon the theme lacks isn't drawn. 

crabshell::run(|cx| {
  cx.set_icon_theme("Adwaita");
  cx.per_output(bar);
});

Symbolic icons, whose names end in -symbolic, are single-color shapes. tint paints every pixel in one color and keeps its alpha, and takes a value or a closure. 

Icon::new("battery-good-symbolic").size(16).tint(TEXT)

Icon files have limits. An SVG may be up to 1 MiB and can't pull in outside files. A PNG may be up to 4 MiB and 1024 pixels a side. XPM icons are skipped. A file past a limit is logged and not drawn.

Images

Image::new(path) shows a PNG, JPEG, GIF, WebP or SVG file, chosen by its extension, in a box of the size you give it. 

Image::new(move || art_path.get())
  .width(96)
  .height(96)
  .fit(Fit::Cover)
  .style(Style::new().radius(12.0).clip(true))
Fit What it does when the shapes differ
Fit::Fill Stretches the picture to the box. The default.
Fit::Contain Shows it whole, centered, with its shape kept.
Fit::Cover Fills the box, centered, with its shape kept. What sticks out is cut off.

The path can be a closure, and a new path loads the new file. A picture is scaled once to the size it is drawn at and cached. A file rewritten in place is read again.

The limits are 32 MiB per file, 8192 pixels a side and 24 million pixels in all. A file that can't be loaded is logged once, and the image keeps what it had.

Files past 64 KiB, pictures drawn larger than 256 by 256 pixels and blurred ones are decoded on a worker thread, so a wallpaper never stalls the shell. Until the picture comes in, the image shows what it showed before, stretched if its size changed. A window's first frame waits up to 250 ms for its pictures, so a wallpaper or a lock screen never shows its background color alone.

Filters

// The same album art, blurred and darkened, behind the card.
Image::new(picture)
  .width(520)
  .height(180)
  .fit(Fit::Cover)
  .blur(18.0)
  .brightness(0.6)
Method What it does
brightness(n) Scales the colors. 1 leaves them, 0 is black and 2 is twice as bright.
contrast(n) 1 leaves the picture, 0 is middle gray and more than 1 is stronger.
saturation(n) 1 leaves the picture, 0 is gray and more than 1 is more vivid.
blur(px) The blur's standard deviation in logical pixels, as in CSS's filter: blur().
tint(color) Paints every pixel in one color and keeps its alpha.

Filters run once on the scaled picture, and the result is cached. A blurred GIF shows its first frame, still. A blur here is twice as strong as the same number in a Shadow.

Animated GIFs

A GIF with several frames plays while it is drawn, at its own speed. playing(false) pauses it. A hidden GIF stops waking the shell.

Transitions

transition says how a new source replaces the old one. 

const FADE: Transition = Transition::new(800).easing(Easing::InOutCubic);

Image::new(move || wallpaper.get()).transition(ImageTransition::crossfade(FADE))
Transition What it looks like
ImageTransition::none() The new picture shows at once. The default.
ImageTransition::crossfade(transition) The new picture fades in over the old one.
ImageTransition::wipe(transition, angle) An edge sweeps across. 0 sweeps toward the top and 90 toward the right.
ImageTransition::circle(transition) A circle grows from the middle.
ImageTransition::pixelate(transition) The old picture breaks into blocks that resolve into the new one.

Each takes a Transition for its length, delay and curve.

A wallpaper

A wallpaper is an image in a panel on the background layer, anchored to all four edges and sized from its monitor. 

fn wallpaper(cx: &Cx, output: &Output, picture: ReadSignal<Option<PathBuf>>) -> PanelWindow {
  let outputs = cx.outputs();
  let name = output.name();
  let size = cx.memo(move || {
    outputs.with(|all| {
      let info = all.iter().find(|info| info.name == name);
      info.map_or((0, 0), |info| (info.width, info.height))
    })
  });
  PanelWindow::new(output)
    .anchors(Edge::Top | Edge::Bottom | Edge::Left | Edge::Right)
    .layer(Layer::Background)
    .exclusive_zone(-1)
    .namespace("wallpaper")
    .child(
      Image::new(move || picture.get().unwrap_or_default())
        .width(move || size.get().0)
        .height(move || size.get().1)
        .fit(Fit::Cover)
        .transition(ImageTransition::crossfade(Transition::new(800)))
        .visible(move || picture.with(Option::is_some)),
    )
}

exclusive_zone(-1) lets it cover the space bars reserve. Change picture from an IPC handler, and crabshell ipc wallpaper set ~/Pictures/lake.jpg crossfades to a new one. A crossfade holds two decoded pictures for its length, and waits at its start until the new one is decoded. A source that can't be loaded ends the transition at once.

Mask regions

mask_region cuts any widget to a shape built from rectangles, rounded rectangles and ellipses, the same Region a window's input mask takes, in the widget's own logical pixels. The edges are antialiased. Pass a closure to animate it: holes that grow over a wallpaper let the windows beneath show through, and each frame repaints only the masked widget. 

let open = cx.signal(false);
let grow = cx.animate(move || if open.get() { 1.0 } else { 0.0 }, Transition::new(450));

Image::new(move || picture.get())
  .width(1920)
  .height(1080)
  .fit(Fit::Cover)
  .mask_region(move || {
    let r = (grow.get() * 260.0) as i32;
    let hole = |x: i32| Region::rect(x - r, 540 - r, 2 * r as u32, 2 * r as u32).radius(32.0);
    Some(Region::rect(0, 0, 1920, 1080).subtract(hole(480)).subtract(hole(1440)))
  })

Clicks still land on the whole widget, holes included. Use the window's mask to let them through. A full-screen picture with a few holes takes about 6 to 8 ms a frame at scale 1 and 22 to 25 ms at scale 2, so mask the smallest widget the effect needs.

More ways to shape what is drawn

  • Masks cut a widget to an ellipse, a gradient's alpha or another image's.
  • follow_content() casts a shadow from text or an icon.
  • cx.quantize_colors finds a picture's main colors.
  • ScreencopyView shows a live picture of a monitor or a window.
