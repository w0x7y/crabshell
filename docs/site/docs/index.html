Crabshell docs

Crabshell is a Rust toolkit for writing a desktop shell on Wayland, from a first bar to launchers, notifications and a lock screen.

What you write

A config is a Cargo project in ~/.config/crabshell. Its main calls crabshell::run with a closure that builds windows out of widgets. This one puts a bar on every monitor, with a button that counts its clicks. 

use crabshell::prelude::*;

fn main() {
  crabshell::run(|cx| cx.per_output(bar));
}

fn bar(cx: &Cx, output: &Output) -> PanelWindow {
  let count = cx.signal(0_u32);
  PanelWindow::new(output)
    .anchors(Edge::Top | Edge::Left | Edge::Right)
    .height(30)
    .child(
      Row::new()
        .padding(4, 8)
        .child(
          Button::new(Text::new(move || format!("clicked {} times", count.get())))
            .on_click(move |_| count.update(|n| *n += 1)),
        )
        .child(Spacer::new())
        .child(Text::new(output.name())),
    )
}
  • Windows hold widgets. A PanelWindow is a surface on one monitor, and cx.per_output builds one for every monitor, now and later. See Windows.
  • Widgets are builder calls. There is no markup language and no macro. See Widgets.
  • A property takes a value or a closure. .height(30) sets it once. A closure runs again when a signal it read changes, and only that widget repaints. See Signals and effects.
  • The desktop arrives as signals. cx.clock(...), cx.sway(), cx.audio() and the other services hand out signals to read.

How it runs

The crabshell command builds your config with cargo, starts it and watches your files. On a save it rebuilds and swaps the shell, in about a second for a small edit. A build that fails leaves the old shell running, and a shell that crashes is started again. The crabshell command has the details.

Inside the shell everything runs on one thread, and nothing is drawn unless something changed.

What it runs on

Crabshell needs a Wayland compositor with layer-shell, such as Sway, Hyprland or labwc. Its test suites run on Sway, and Hyprland is checked by hand. Some features need more from the compositor, and this table says which. A feature the compositor lacks logs one line and stays empty.

Versions

These pages describe version 0.9. A new minor version can change the API. The line crabshell = "0.9" in your Cargo.toml keeps you on 0.9 until you change it. docs.rs has reference docs for every public item.
