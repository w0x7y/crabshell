Layout

Layout is flexbox and grid, the same model as CSS, written as method calls and style fields.

The basics

  • Every size is in logical pixels. The renderer multiplies by the monitor's scale.
  • A window's child fills the window. A panel anchored left and right gets its width from the compositor.
  • A row or column is as large as its content. Children stretch across it and pack at its start.
  • Content that doesn't fit overflows and still draws. clip(true) in the style cuts it off.

Rows and columns

Setting In a row In a column
gap(8) 8 pixels between neighbors The same
padding(4, 8) 4 pixels above and below, 8 at the sides The same
align(...) Up and down Left and right
justify(...) Left and right Up and down

align takes Align::Start, Center, End or Stretch, the default. justify takes Justify::Start, Center, End, SpaceBetween, SpaceAround or SpaceEvenly. To center one thing in a box, use both. 

Column::new()
  .align(Align::Center)
  .justify(Justify::Center)
  .child(Text::new("Locked"))

A Spacer takes whatever width is left, which pushes things apart. 

Row::new()
  .child(workspaces)
  .child(Spacer::new())
  .child(clock)

Two spacers share the leftover space, which centers the clock between its neighbors. If the two sides differ in width, that is off the bar's true center. To pin it there, use an absolute position. 

Row::new()
  .child(workspaces)
  .child(Spacer::new())
  .child(clock)
  .child(Spacer::new())
  .child(tray)

Sizes

Field What it sets
width(px), height(px) A fixed size.
min_width, min_height, max_width, max_height Limits on a size that follows the content or the space.
grow(n) Its share of the leftover space in a row or column. 0 takes none.
shrink(n) How much it gives up when room is short. 0 never shrinks.
basis(px) The size it starts from before growing or shrinking. 
const SIDEBAR: Style = Style::new().width(240.0);
const CONTENT: Style = Style::new().grow(1.0);

Row::new()
  .child(Column::new().style(SIDEBAR))
  .child(Column::new().style(CONTENT))

A size can follow a signal like anything else.

Row::new().style(move || FILL.width(2.0 * volume.get() as f32))

Padding

padding(vertical, horizontal) in a style sets the space inside a widget's edges, and padding_top, padding_right, padding_bottom and padding_left set one side each. A row's, column's or grid's own padding method wins over its style's.

Buttons center their child

A Button is as large as its child plus its padding, and centers the child. For a list row that should start at the left, give the row the width it should fill. 

// The row is as wide as the list less the button's padding, so its text starts at the left.
const LINE: Style = Style::new().width(314.0);

Button::new(Row::new().style(LINE).child(icon).child(label)).style(ITEM)

Wrapping and reversing

wrap(true) starts a new line for children that don't fit. reverse(true) runs a row right to left or a column bottom to top. 

// Chips that flow onto as many lines as they need.
names.iter().fold(Row::new().wrap(true).gap(8), |row, name| row.child(chip(name)))

Grids

Grid places children row by row into equal columns. A child spans cells with span(columns, rows), and in its cell align_self places it up and down and justify_self left and right. 

// A month: seven columns, with the days before the 1st as one empty cell.
let mut month = Grid::new().columns(7).gap(4);
if blanks > 0 {
  month = month.child(Row::new().style(Style::new().span(blanks, 1)));
}
for day in 1..=days {
  month = month.child(Text::new(day.to_string()));
}

Stacks and absolute positions

A Stack draws its children on top of each other, each stretched to the size of the largest. align_self and justify_self place a child in the cell instead. 

Stack::new()
  .child(album_art)
  .child(Text::new("2:41").style(Style::new().align_self(Align::End).justify_self(Align::End)))

Setting left, top, right or bottom takes a widget out of its parent's flow, as CSS's position: absolute does. It is placed from those edges and no longer adds to the parent's size. 

// A badge in the top right corner of an icon.
const BADGE: Style = Style::new()
  .top(0.0)
  .right(0.0)
  .width(10.0)
  .height(10.0)
  .radius(5.0)
  .background(Color::rgb(0xf3, 0x8b, 0xa8));

Stack::new().child(Icon::new("mail-unread")).child(Row::new().style(BADGE))

z(n) orders siblings for drawing and for the pointer, lowest first. Tab order always follows child order.

One child placed differently

align_self overrides the container's align for one child. 

Row::new()
  .align(Align::Center)
  .child(title)
  .child(Text::new("beta").style(Style::new().align_self(Align::Start)))

Visibility

visible(false) removes a widget from the layout. Its bindings, state and children stay, so showing it again is cheap. To free those too, build it in a child context. 

Text::new("away").visible(move || away.get())

What moves without a layout

translate, scale and rotate move where a widget is drawn and clicked, never where it is laid out. Use them for motion, since they only repaint.

Reading a widget's place

geometry(signal) on any widget writes its rectangle to a Signal<Rect> after each layout that moves it, in the window's logical pixels, with scroll offsets applied and transforms left out.
