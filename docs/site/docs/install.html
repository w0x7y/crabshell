crabshell Docs

Install and run

Three commands put a bar on every monitor. The first build takes a few minutes, and after that an edit shows in about a second.

What you need

  • Rust 1.99 or newer, with cargo. rustup installs both.
  • A compositor with layer-shell, such as Sway, Hyprland or labwc. The template bar shows Sway's workspaces. On Hyprland, start from the hyprland example.
  • Linux 5.3 or newer.
  • pkg-config, and the development files of fontconfig, libpulse, libxkbcommon and PAM. On Debian or Ubuntu: 
$ sudo apt install pkg-config libfontconfig1-dev libpulse-dev libxkbcommon-dev libpam0g-dev

Three more are optional. Without one, its part of the bar stays empty.

Program What uses it
PulseAudio or pipewire-pulse The volume
A D-Bus session bus The tray, media players and notifications
A notification daemon such as mako The note crabshell run sends when an edit doesn't build

Install

$ cargo install --locked crabshell-cli
$ crabshell init
$ crabshell run
  1. cargo install puts the crabshell command in ~/.cargo/bin.
  2. crabshell init writes a Cargo project to ~/.config/crabshell. It refuses if that directory exists, so it never overwrites a config.
  3. crabshell run builds the config and starts it. The first build compiles the toolkit, which took just under three minutes on 12 cores.

A bar then shows at the top of every monitor, with Sway's workspaces, the tray, the volume and the clock. Stop any other bar first. 

~/.config/crabshell/
├── Cargo.toml
└── src/
    └── main.rs

Build output goes to ~/.cache/crabshell/target. XDG_CONFIG_HOME and XDG_CACHE_HOME move both directories.

Edit it while it runs

Leave crabshell run running and change src/main.rs. Each save rebuilds the config and swaps the bar. A one-line edit builds in about 0.7 s. The new bar starts beside the old one, which exits once the new one is ready, so the bar never leaves the screen.

  • The edit doesn't build. The old bar stays. The errors print in the terminal, and the first one arrives as a notification.
  • The new shell crashes. It is started again. After three crashes within a minute, crabshell run goes back to the last build that worked.
  • You only want to check. crabshell check runs cargo check on the config.

Values kept with cx.persist survive each swap. rust-analyzer works in ~/.config/crabshell as in any Cargo project.

Start it with your session

# Sway: ~/.config/sway/config
exec ~/.cargo/bin/crabshell run

# Hyprland: ~/.config/hypr/hyprland.conf
exec-once = ~/.cargo/bin/crabshell run

crabshell run calls cargo, so cargo must be on the PATH your session starts with. A PATH set only in your shell's startup file isn't enough under a display manager.

Build against a clone

$ git clone https://github.com/w0x7y/crabshell
$ cd crabshell
$ cargo run --release -p crabshell --example launcher

The other examples run the same way. crabshell init --path <clone> writes a config that depends on the clone instead of crates.io.

Update or remove it

Run cargo install --locked crabshell-cli again to update the command, and cargo update in ~/.config/crabshell for the newest 0.9 library. To remove everything, run cargo uninstall crabshell-cli and delete ~/.config/crabshell and ~/.cache/crabshell.
