crabshell Docs

Styles

A Style is a plain value with optional fields. Every method that builds one is a const fn, so a theme is a list of constants.

Styles are constants

const TEXT: Color = Color::hex("#cdd6f4");
const SURFACE: Color = Color::rgb(0x31, 0x32, 0x44);

const CHIP: Style = Style::new().background(SURFACE).radius(14.0).padding(6, 12);
const CHIP_ON: Style = CHIP.background(Color::rgb(0x89, 0xb4, 0xfa)).color(Color::rgb(0x1e, 0x1e, 0x2e));

A style can start from another, as CHIP_ON starts from CHIP. There are no selectors, classes or cascade. A widget has the one style you give it, and a closure changes it at run time. 

Button::new(label).style(move || if on.get() { CHIP_ON } else { CHIP })

a.merge(b) lays every field b sets over a. Buttons do this with their hover, pressed and focus styles, so a hover style needs only the fields that change. 

const HOVER: Style = Style::new().background(Color::rgb(0x58, 0x5b, 0x70));
Button::new(label).style(CHIP).hover_style(HOVER)

Every field

Field What it sets
background(color) A solid fill.
gradient(gradient) A gradient fill, over the background.
color(color) The text color. Inherited by text inside.
font(font) The family, size, weight, italic, letter spacing and OpenType features. Inherited by text inside.
text_align(TextAlign) Where lines sit in the text's box: Start, Center, End or Justify. Inherited.
line_height(n) The line height, a multiple of the font size. Inherited.
underline(bool), strikethrough(bool) Lines under or through the text. Inherited.
padding(v, h), padding_top and the other three Space inside the edges.
radius(r), radii(tl, tr, br, bl) Rounded corners, all four or each.
border(width, color) A border drawn inside the edge.
border_dash(on, off) Dashes the border.
shadow(shadow) A shadow behind the box, or behind what it draws.
opacity(0.0..=1.0) Fades the widget and everything inside as one layer.
clip(bool) Cuts children to the inside of the border and its corners.
mask(mask) Keeps the widget only where the mask is opaque.
width, height, min_width, min_height, max_width, max_height Sizes.
grow, shrink, basis How it shares space in a row or column.
align_self, justify_self Its own place in its parent.
left, top, right, bottom, z Absolute positions and stacking order.
span(columns, rows) The cells it takes in a grid.
translate(x, y), scale(s), rotate(degrees), origin(x, y) Transforms.
transition(transition) How a change to this style fades in.

Only color, font, text_align, line_height, underline and strikethrough are inherited. A Text uses the nearest ones set above it.

Colors

Color::rgb(0x1e, 0x1e, 0x2e)
Color::rgba(0x1e, 0x1e, 0x2e, 0xd8)   // alpha from 0 to 255
Color::hex("#1e1e2e")
Color::hex("#1e1e2ed8")
Color::hsl(240.0, 0.21, 0.15)         // hue in degrees, the rest from 0 to 1
Color::hsla(240.0, 0.21, 0.15, 0.85)

All of these are const fn. A badly formed string given to Color::hex in a constant is a compile error. Four more methods derive one color from another. 

const ACCENT: Color = Color::hex("#89b4fa");
const ACCENT_DIM: Color = ACCENT.with_alpha(0.25);
const ACCENT_HOVER: Color = ACCENT.lighter(0.08);
const ACCENT_PRESSED: Color = ACCENT.darker(0.08);
const BLEND: Color = ACCENT.mix(Color::hex("#f38ba8"), 0.5);

lighter and darker add to the HSL lightness. mix blends each channel, with 0 giving the first color and 1 the other.

Fonts

const BODY: Font = Font::new("Inter", 13.0);
const BOLD: Font = Font::new("Inter", 13.0).weight(700);
const CLOCK: Font = Font::new("Inter", 24.0)
  .letter_spacing(0.5)
  .features(&[FontFeature::TABULAR_NUMBERS]);
const QUOTE: Font = BODY.italic();

The family is any name fontconfig knows, including sans-serif and monospace, and the size is in logical pixels. Characters the font lacks come from fontconfig's fallbacks. The shell loads only the font files your styles name.

Letter spacing is extra pixels after each glyph. Features are OpenType tags: TABULAR_NUMBERS keeps every digit the same width, so a clock doesn't jitter, and FontFeature::new(*b"zero", 1) names any other inside a const.

To ship a font with your config, call cx.add_font(include_bytes!("fonts/Inter.ttf")) before the first window. The shell uses it for that family, weight and slant without asking fontconfig, which also makes the first frame faster.

Borders and corners

const CARD: Style = Style::new()
  .radius(12.0)
  .border(1.0, Color::rgba(0xcd, 0xd6, 0xf4, 0x30));
const TAB: Style = Style::new().radii(8.0, 8.0, 0.0, 0.0);   // top-left, top-right, bottom-right, bottom-left
const DROP_ZONE: Style = Style::new().border(2.0, ACCENT).border_dash(6.0, 4.0).radius(8.0);
const DOTTED: Style = DROP_ZONE.border_dash(0.0, 5.0);

Each corner is clamped to half the box's shorter side, so radius(999.0) makes a pill. border_dash(on, off) dashes the border, and an on of 0 draws round dots. The background, a clip, a shadow and the pointer's hit area all follow the corners.

Gradients

Gradient::linear(90.0, from, to)   // along a line: 0 runs bottom to top, 90 left to right
Gradient::radial(from, to)         // from the middle out to the farthest corner
Gradient::sweep(0.0, from, to)     // around the middle, clockwise from 12 o'clock

.stop(at, color) adds a color between the two ends, at a place from 0 to 1. A gradient holds at most four colors. 

const BAR: Style = Style::new().gradient(
  Gradient::linear(90.0, Color::rgba(0x1e, 0x1e, 0x2e, 0xd8), Color::rgba(0x31, 0x32, 0x44, 0xd8)),
);
const RING: Gradient = Gradient::sweep(0.0, GREEN, PEACH).stop(0.5, YELLOW);

Shadows

const CARD: Style = Style::new()
  .background(SURFACE)
  .radius(8.0)
  .shadow(Shadow::new(0.0, 2.0, 8.0, Color::rgba(0, 0, 0, 0xa0)));

Shadow::new(x, y, blur, color) casts the box's shadow, with a blur that works as CSS's box-shadow does.

Method What it does
spread(px) Grows the shadow's shape before it is blurred.
cut_out() Leaves the shadow out under the box itself, for a translucent background.
follow_content() Casts the shadow from what the widget draws, through its alpha, which puts one behind text or an icon. 
// A title readable over any album art.
const TITLE: Style = Style::new().shadow(Shadow::new(0.0, 1.0, 4.0, Color::rgba(0, 0, 0, 0xc0)).follow_content());

A shadow draws outside its widget, so leave room for it. A window ends at its edge. A content shadow costs a blur each time the content repaints, and one that would reach more than 64 pixels isn't drawn.

Opacity, clips and masks

opacity fades a widget and its children as one layer. clip(true) cuts children to the inside of the border. A mask keeps a widget only where the mask is opaque. 

Style::new().mask(Mask::ellipse())                       // a round avatar
Style::new().mask(Mask::gradient(Gradient::linear(90.0, Color::rgba(0, 0, 0, 255), Color::rgba(0, 0, 0, 0))))   // fades out to the right
Style::new().mask(Mask::image("/usr/share/shapes/squircle.png"))

A gradient mask uses only its colors' alpha. Mask::image takes a &'static str, so the style stays a constant. A mask doesn't change where the pointer hits.

Transforms

SPINNER.rotate(turn.get() * 360.0)
CARD.translate(0.0, (1.0 - shown.get()) * 80.0).scale(0.9 + 0.1 * shown.get())

translate(x, y) moves a widget and everything inside it, scale(s) resizes it and rotate(degrees) turns it clockwise. origin(x, y) is the point it scales and turns around, as fractions of its box, (0.5, 0.5) by default.

Transforms change where a widget is drawn and hit, never the layout, so nothing around it moves.

Fades between styles

Give a style a transition, and a change to that style fades in. 

const TAB: Style = Style::new().radius(6.0).transition(Transition::new(150));
const TAB_HOVER: Style = Style::new().background(Color::rgba(0xff, 0xff, 0xff, 0x24));

Button::new(label).style(TAB).hover_style(TAB_HOVER)

The hover background now fades in over 150 ms and back out. Backgrounds, gradients, shadows, text colors, borders, radii, opacity and transforms fade. Sizes, padding and fonts change at once. Timers and motion lists the curves.

Keeping a theme tidy

Styles are ordinary constants, so a module of colors and styles is enough. 

use crabshell::prelude::*;

pub const BASE: Color = Color::hex("#1e1e2e");
pub const TEXT: Color = Color::hex("#cdd6f4");
pub const ACCENT: Color = Color::hex("#89b4fa");

pub const BAR: Style = Style::new().background(BASE).color(TEXT).font(Font::new("Inter", 13.0));
pub const CHIP: Style = Style::new().padding(2, 8).radius(4.0);
pub const CHIP_ON: Style = CHIP.background(ACCENT).color(BASE);

For colors taken from a wallpaper at run time, see cx.quantize_colors.
