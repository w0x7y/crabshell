crabshell Docs

Desktop services

A service connects the shell to something outside it, such as the audio server or the battery. Each hands out read-only signals and a few methods.

How every service behaves

  • You ask any context for it, with cx.audio(), cx.network() and the rest.
  • It starts on first use and is shared. Ten bars that call cx.bluetooth() share one connection.
  • While the daemon behind it isn't running, its signals hold None, false or an empty list. Most fill in when the daemon starts.
  • It wakes the shell only when something changed. The two exceptions are a seconds clock and an audio level meter.

Lists hold plain structs, such as Vec<BluetoothDevice>. A get() clones the list, so read long ones with with. 

let connected = devices.with(|all| all.iter().filter(|d| d.connected).count());

Clock

let clock = cx.clock(Precision::Minute);
Text::new(move || clock.get().strftime("%a %d %b  %H:%M").to_string())

cx.clock(precision) is a ReadSignal<jiff::Zoned>, the time in the system's time zone. Precision::Minute changes on each whole minute and Precision::Second on each second, which wakes the shell sixty times as often. Precision::Day changes at each local midnight, for a date shown without a clock.

The value is a jiff Zoned, so strftime, hour(), weekday() and date arithmetic all work. The crate is re-exported as crabshell::jiff. The clock is right at once after a suspend and follows a changed time zone.

Audio

cx.audio() talks to PulseAudio, or to PipeWire through pipewire-pulse. 

let sink = cx.audio().default_sink();

Button::new(Text::new(move || match sink.get() {
  Some(s) if s.muted => "muted".to_string(),
  Some(s) => format!("vol {}%", s.volume_percent),
  None => "no audio".to_string(),
}))
.on_click(|cx| cx.audio().toggle_mute())
.on_scroll(|cx, steps| cx.audio().change_volume(steps * 5))
Signal What it holds
default_sink() Option<Sink>: the output in use, with its name, volume_percent and muted.
default_source() Option<AudioNode>: the microphone in use.
sinks(), sources() Vec<AudioNode>: every output and input, each with name, description, volume_percent, muted, and per-channel volumes and channels.
streams() Vec<AudioStream>: every program playing sound, with index, app_name, title, icon_name, its sink, volume_percent and muted.
Method What it does
change_volume(percent) Adds to the default sink's volume. Negative lowers it.
toggle_mute() Mutes or unmutes the default sink.
set_default_sink(name), set_default_source(name) Picks the output or input in use.
set_sink_volume(name, percent), set_sink_mute(name, muted) One output. set_source_volume and set_source_mute do the same for an input.
set_stream_volume(index, percent), set_stream_mute(index, muted) One program's sound.
move_stream(index, sink) Sends a program's sound to another output.
set_sink_volumes(name, &[percent]) Each channel on its own. set_source_volumes and set_stream_volumes exist too.

With no server, the sink is None. The service retries every 2 s for a minute after startup, then stops and logs once.

Level meters

cx.audio().peaks(target) is a ReadSignal<Vec<f32>> with the current level of each channel. The target is a PeakTarget::Sink(name), Source(name) or Stream(index), as a value or a closure, or None for no meter. 

let levels = cx.audio().peaks(move || mic.get().map(|m| PeakTarget::Source(m.name)));

A meter wakes the shell 25 times a second while its target plays, so build one only while it is on screen.

Tray

The Tray widget shows one icon per tray item, in the order they registered. 

Tray::new().icon_size(18).menu_style(MENU)

A left click activates an item, or opens its menu when the item is only a menu. A right click opens the menu, a middle click is the secondary action, and scrolling scrolls the item. icon_size defaults to 16, and menu_style styles the menu's popup. Crabshell runs the tray's watcher itself when nothing else does.

For a tray of your own design, cx.tray() gives the data.

Method What it gives or does
items() Vec<TrayItem>, each with id, app_id, title, status, category, tooltip, icon_name, icon_pixmaps and item_is_menu.
item.icon(size) The item's icon as an Option<IconSource>, ready for Icon::new.
activate(id), secondary_activate(id), scroll(id, steps) What a click and a scroll send to the application.
open_menu(id), menu(), menu_event(id, entry), open_submenu(entry), close_menu() An item's menu as a TrayMenu of MenuEntry values, and a click on one.

TrayStatus is Passive, Active or NeedsAttention.

Notifications

cx.notifications() makes the shell the desktop's notification server. If another daemon such as mako is running, the shell waits for it to leave, so stop the other one first. 

let popups = cx.notifications().popups();

Column::new().gap(8).children_keyed(
  move || popups.get(),
  |notification: &Notification| notification.id,
  |_cx, notification| {
    Button::new(
      Column::new()
        .child(Text::new(move || notification.get().summary).style(SUMMARY))
        .child(Text::new(move || notification.get().body)),
    )
    .style(TOAST)
    .on_click(move |cx| cx.notifications().dismiss(notification.get().id))
  },
)
Signal What it holds
popups() The notifications still showing, newest first. Each stays for its timeout. One with Timeout::Never or Urgency::Critical stays until dismissed.
list() The history, oldest first, until each is dismissed, picked or closed by its application.
Method What it does
dismiss(id) Takes one away and tells its application.
invoke(id, key) Tells the application the user picked the action key, then takes the notification away unless it is resident.
clear() Dismisses every one.
on_closed(handler) Calls handler with each notification that leaves the history and a CloseReason of Expired, Dismissed or CloseRequested.

A Notification has id, app_name, app_icon, summary, body, actions, urgency, timeout, image, desktop_entry, category, resident, transient and received.

A reload keeps the history and the popups showing, with the time each had left, so apps' ids go on. A notification sent in the moment the shells swap is still lost.

actions is a list of (key, label) pairs. Show the labels as buttons and pass the key to invoke. The key default is what a click on the notification itself means.

The desktop and motion examples show toasts, and control shows the history.

Media players

cx.mpris() lists every program that plays media and speaks MPRIS. 

let players = cx.mpris().players();
let playing = cx.memo(move || {
  let players = players.get();
  let active = players.iter().find(|p| p.status == PlaybackStatus::Playing);
  active.or(players.first()).cloned()
});

A Player has an id to pass to the methods, an identity such as "Firefox", the status (Playing, Paused or Stopped), the title, artists, album, art_url and length, and can_play, can_pause, can_go_next, can_go_previous, can_seek and can_control. A track that sends no title, as a file without tags in VLC, is named by its file's name. volume, shuffle and loop_status are None when the player doesn't offer them.

The methods each take a player's id: play_pause, play, pause, stop, next, previous, seek(id, seconds), set_position(id, position), set_volume(id, volume), set_shuffle(id, on), set_loop(id, status) and raise(id), which asks the player to show its window.

MPRIS doesn't announce the position as it moves. To show it ticking, read a clock and ask the player. 

let clock = cx.clock(Precision::Second);
Text::new(move || {
  clock.get();   // run again each second
  let at = player.get().position_at(std::time::Instant::now());
  format!("{}:{:02}", at.as_secs() / 60, at.as_secs() % 60)
})

For art on disk, art_url is a file:// address, which you turn into a path for an Image. Art served over https isn't fetched.

Network

cx.network() reads NetworkManager.

let network = cx.network();
let (devices, wifi) = (network.devices(), network.wifi_networks());

Text::new(move || {
  if let Some(wifi) = wifi.get().into_iter().find(|wifi| wifi.connected) {
    return format!("{} {}%", wifi.ssid, wifi.strength);
  }
  let wired = devices.get().into_iter().any(|device| {
    device.kind == NetworkKind::Ethernet && device.state == NetworkState::Connected
  });
  if wired { "wired" } else { "offline" }.to_owned()
})
Signal What it holds
wifi_enabled() Whether Wi-Fi is on.
connectivity() Connectivity::Full, Limited, Portal, None or Unknown. Portal means a login page is in the way.
devices() Vec<NetworkDevice>: each with path, interface, kind (Ethernet, Wifi or Other), state, the connection in use, fail_reason, has_link and link_speed.
wifi_networks() Vec<WifiNetwork>: the networks in range, strongest first, each with ssid, strength from 0 to 100, secured, security, connected and its device.
saved_connections() Vec<SavedConnection>: uuid, id, kind and the settings without secrets.
Method What it does
set_wifi_enabled(bool) Turns Wi-Fi on or off.
scan(device) Asks a Wi-Fi device, by its path, to look for networks.
connect(&network, password) With None, uses the connection saved for that network. With Some(password), saves a new one.
disconnect(device) Disconnects a device.
forget(uuid), clear_secrets(uuid) Deletes a saved connection, or only its password.

A request NetworkManager refuses is logged, and the password never is.

Bluetooth

cx.bluetooth() reads BlueZ.

Signal What it holds
adapters() Vec<BluetoothAdapter>: path, name, address, powered, state and discovering.
devices() Vec<BluetoothDevice>: path, adapter, address, name, icon, connected, state, paired, trusted and battery, a percent when the device reports one.

The methods take a path: set_powered(adapter, bool), start_discovery(adapter), stop_discovery(adapter), connect(device), disconnect(device), pair(device), set_trusted(device, bool) and forget(device).

cx.bluetooth_agent() makes the shell BlueZ's pairing agent. Its request() is a ReadSignal<Option<PairingRequest>> with the device's path and a kind saying what BlueZ wants: a PIN code or passkey to type, one to show, a passkey to confirm, or an authorization. Answer with answer_pin_code(code), answer_passkey(n), accept() or reject(). A pairing the shell starts with pair reaches it at once; make_default() makes it the agent for pairings other programs and devices start too. 

Button::new(Text::new(move || device.get().name))
  .on_click(move |cx| {
    let device = device.get();
    if device.connected {
      cx.bluetooth().disconnect(&device.path);
    } else {
      cx.bluetooth().connect(&device.path);
    }
  })

Battery and power

cx.upower() reads batteries and power supplies from UPower. 

let battery = cx.upower().display_device();
Text::new(move || match battery.get().filter(|b| b.present) {
  Some(b) if b.state == BatteryState::Charging => format!("bat {:.0}%+", b.percent),
  Some(b) => format!("bat {:.0}%", b.percent),
  None => String::new(),
})
Signal What it holds
display_device() Option<PowerDevice>: the one battery to show, which UPower combines from all of them.
devices() Vec<PowerDevice>: every battery and supply, including a mouse's or a headset's.
on_battery() Whether the machine runs on battery.

A PowerDevice has kind, model, icon_name, present, state, percent, time_to_empty, time_to_full and energy_rate in watts. BatteryState is Charging, Discharging, Empty, FullyCharged, PendingCharge, PendingDischarge or Unknown. A desktop with no battery has a display device that isn't present.

cx.power_profiles() reads power-profiles-daemon. active() is the current PowerProfile (PowerSaver, Balanced or Performance), available() lists the ones the machine offers, and set(profile) switches. degradation() is a PerformanceDegradation of None, LapDetected, HighTemperature or Other.

Idle time

cx.idle_monitor(timeout) is a ReadSignal<bool> that turns true once no key, pointer or touch input came for that long, and false at the next input. 

let away = cx.idle_monitor(Duration::from_secs(300));
cx.effect(move || {
  if away.get() {
    locked.set(true);
  }
});

The compositor does the timing, so nothing wakes the shell while it waits. A window with inhibit_idle set, yours or a video player's, holds the timeout off.

Sleep and power

cx.logind() has power_off(), reboot(), suspend() and hibernate(), and preparing_for_sleep(), true while the machine goes to sleep. A lock screen locks before suspend by holding the sleep until its lock shows: 

let logind = cx.logind();
let sleeping = logind.preparing_for_sleep();
cx.effect(move || {
  if sleeping.get() {
    locked.set(true);
  }
});
logind.delay_sleep_until(move || shown.get());

shown is the signal cx.session_lock gives.

Brightness

cx.brightness().devices() lists the backlights, each with name, brightness and max_brightness, and follows the brightness keys. set(name, value) goes through logind, so it needs no root.

CPU, memory and temperatures

let stats = cx.system_stats(Duration::from_secs(2));
Text::new(move || format!("{:.0}%", stats.get().cpu * 100.0))

SystemStats has cpu and cpus from 0 to 1, memory_total, memory_available, swap_total, swap_free and temperatures. It samples only while the context that asked lives, so ask inside the popup that shows it, once. The reads run on a thread of their own, so the first value shows a moment after the bar.

Date names

let locale = cx.locale();
let clock = cx.clock(Precision::Minute);
Text::new(move || locale.get().strftime(&clock.get(), "%A %d %B"))

The names come from glibc for LC_TIME or LANG. months_standalone is the form for a calendar's header.

Short sounds

cx.audio().play_sound(path) plays a WAV file once.
