crabshell Docs

Your first bar

crabshell init writes a bar with workspaces, a tray, the volume and a clock. This page builds that file a piece at a time.

Keep crabshell run running while you follow along. Each save swaps the bar.

The smallest shell

use crabshell::prelude::*;

fn main() {
  crabshell::run(|cx| cx.per_output(bar));
}

fn bar(_cx: &Cx, output: &Output) -> PanelWindow {
  PanelWindow::new(output)
    .anchors(Edge::Top | Edge::Left | Edge::Right)
    .height(30)
    .child(Text::new("hello"))
}
  • crabshell::run connects to the compositor, calls your closure once and runs the event loop. It never returns.
  • cx is the context. You make signals with it and ask it for services.
  • cx.per_output(bar) calls bar for each monitor, including one plugged in later. Unplug a monitor and its window goes, with everything bar made for it.
  • PanelWindow::new(output) is a surface on that monitor. Anchored to the top, left and right, it spans the top edge. Sizes are in logical pixels.

The text is black on a transparent window, since nothing has a style yet.

A style is a constant

const BAR: Style = Style::new()
  .background(Color::rgb(0x1e, 0x1e, 0x2e))
  .color(Color::rgb(0xcd, 0xd6, 0xf4))
  .font(Font::new("Inter", 13.0));

Add .style(BAR) to the window. Every Style method is a const fn, so a theme is a list of constants, and one style can start from another. 

const WS: Style = Style::new().padding(2, 8).radius(4.0);
const WS_FOCUSED: Style = WS.background(Color::rgb(0x45, 0x47, 0x5a));

Text takes its color and font from the nearest widget above it that sets them. Nothing else is inherited. Styles lists every field.

A row, and a clock

A window holds one child. For several things side by side, make that child a Row. 

fn bar(cx: &Cx, output: &Output) -> PanelWindow {
  let clock = cx.clock(Precision::Minute);

  PanelWindow::new(output)
    .anchors(Edge::Top | Edge::Left | Edge::Right)
    .height(30)
    .exclusive_zone(30)
    .style(BAR)
    .child(
      Row::new()
        .gap(8)
        .padding(4, 8)
        .child(Text::new(output.name()))
        .child(Spacer::new())
        .child(Text::new(move || {
          clock.get().strftime("%a %d %b  %H:%M").to_string()
        })),
    )
}

cx.clock(Precision::Minute) is a signal that holds the time and changes once a minute. The closure given to Text::new reads it, which subscribes the closure. When the minute changes, the closure runs again and that one text repaints. Between minutes the shell is asleep.

This is the rule to remember. A plain value sets a property once, and a closure keeps it up to date.

Spacer takes the leftover width, which pushes the clock to the right. exclusive_zone(30) keeps other windows from sitting under the bar.

Workspaces

let workspaces = cx.sway().workspaces();
let output_name = output.name();

workspaces() is a signal holding a Vec<Workspace>. A list that changes needs children_keyed, which takes three closures. 

Row::new().gap(4).children_keyed(
  // The items. This runs again when the workspaces change.
  move || {
    workspaces
      .get()
      .into_iter()
      .filter(|w| w.output == output_name)
      .collect::<Vec<_>>()
  },
  // A key that names each item.
  |w| w.id,
  // The widget for one item.
  |_cx, ws| {
    Button::new(Text::new(move || ws.get().name))
      .style(move || if ws.get().focused { WS_FOCUSED } else { WS })
      .on_click(move |cx| cx.sway().focus_workspace(&ws.get().name))
  },
)

The third closure runs once per key, and its button is kept while that key stays in the list. ws is a Memo<Workspace> that changes with that workspace, so focusing another one repaints two buttons and builds none.

Closures say move because they outlive the function. Signals and memos are Copy, so one can move into several closures. output_name is a String, so it is made before the closure that takes it.

The volume

let sink = cx.audio().default_sink();
Button::new(Text::new(move || match sink.get() {
  Some(s) if s.muted => "muted".to_string(),
  Some(s) => format!("vol {}%", s.volume_percent),
  None => "no audio".to_string(),
}))
.on_click(|cx| cx.audio().toggle_mute())
.on_scroll(|cx, steps| cx.audio().change_volume(steps * 5))

default_sink() holds an Option<Sink>, which is None while no audio server answers. Every service works this way. Something that isn't running gives None or an empty list, never a panic. on_scroll gets whole wheel steps, positive for up.

The tray

.child(Tray::new().icon_size(18))

Tray is a finished widget with one icon per tray item.

The whole file

This is what crabshell init writes. Its Cargo.toml is on the command's page. 

use crabshell::prelude::*;

const BAR: Style = Style::new()
  .background(Color::rgb(0x1e, 0x1e, 0x2e))
  .color(Color::rgb(0xcd, 0xd6, 0xf4))
  .font(Font::new("Inter", 13.0));
const WS: Style = Style::new().padding(2, 8).radius(4.0);
const WS_FOCUSED: Style = WS.background(Color::rgb(0x45, 0x47, 0x5a));

fn main() {
  crabshell::run(|cx| cx.per_output(bar));
}

fn bar(cx: &Cx, output: &Output) -> PanelWindow {
  let clock = cx.clock(Precision::Minute);
  let workspaces = cx.sway().workspaces();
  let sink = cx.audio().default_sink();
  let output_name = output.name();

  PanelWindow::new(output)
    .anchors(Edge::Top | Edge::Left | Edge::Right)
    .height(30)
    .exclusive_zone(30)
    .style(BAR)
    .child(
      Row::new()
        .gap(8)
        .padding(4, 8)
        .child(Row::new().gap(4).children_keyed(
          move || {
            workspaces
              .get()
              .into_iter()
              .filter(|w| w.output == output_name)
              .collect::<Vec<_>>()
          },
          |w| w.id,
          |_cx, ws| {
            Button::new(Text::new(move || ws.get().name))
              .style(move || if ws.get().focused { WS_FOCUSED } else { WS })
              .on_click(move |cx| cx.sway().focus_workspace(&ws.get().name))
          },
        ))
        .child(Spacer::new())
        .child(Tray::new().icon_size(18))
        .child(
          Button::new(Text::new(move || match sink.get() {
            Some(s) if s.muted => "muted".to_string(),
            Some(s) => format!("vol {}%", s.volume_percent),
            None => "no audio".to_string(),
          }))
          .on_click(|cx| cx.audio().toggle_mute())
          .on_scroll(|cx, steps| cx.audio().change_volume(steps * 5)),
        )
        .child(Text::new(move || {
          clock.get().strftime("%a %d %b  %H:%M").to_string()
        })),
    )
}

Split it up

A widget is a value, so a function can return one. As the file grows, move each part into a function that takes a &Cx. 

fn volume(cx: &Cx) -> Button {
  let sink = cx.audio().default_sink();
  Button::new(Text::new(move || match sink.get() {
    Some(s) if s.muted => "muted".to_string(),
    Some(s) => format!("vol {}%", s.volume_percent),
    None => "no audio".to_string(),
  }))
  .on_click(|cx| cx.audio().toggle_mute())
}

The bar then reads .child(volume(cx)). Asking for cx.audio() in ten places still makes one connection.
