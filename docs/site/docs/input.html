crabshell Docs

Pointer and keyboard

A Button is how a widget hears the pointer. Keys go to whatever has the keyboard focus, then up to the window.

Every handler receives a &Cx first, so it can reach services, open popups and set signals. A handler that panics is logged and never called again.

Clicks

Button::new(Text::new("vol"))
  .on_click(|cx| cx.audio().toggle_mute())
  .on_right_click(|cx| cx.exec_detached(["pavucontrol"]))
Handler When it runs
on_click The left button was pressed and released on the button.
on_right_click, on_middle_click The same for the other two buttons.
on_back, on_forward A click of the mouse's side buttons.
on_press The moment the left button goes down.
on_release The left button came up after going down on this button.
on_double_click Two clicks within 400 ms and 5 pixels. It replaces the second on_click.
on_long_press The left button was held for 800 ms without moving. The release then doesn't click.
on_any_press Any pointer button went down over the button. The handler gets which one as a PointerButton, as a click catcher that closes a panel at the first press needs.

The pointer goes to the deepest enabled button under it. A touchscreen's first finger acts as the left button.

Hover

hover_style and pressed_style need no code. When something else should react to the hover, bind a signal. 

let hovered = cx.signal(false);
Button::new(
  Row::new()
    .child(Text::new(move || title.get()))
    .child(Text::new("×").visible(move || hovered.get())),
)
.hovered(hovered)

hovered(signal) is true while the pointer is over the button or anything inside it, inner buttons included. Several buttons may share one signal. pointer_position(signal) writes the pointer's place in the button to a Signal<Option<Point>>.

cursor(shape) takes any CursorShape, such as Pointer, Default, Text, Grab, Grabbing, Crosshair, NotAllowed, EwResize or NsResize. While a button drags, the pointing hand and the open hand show as the grabbing hand until the release.

Scrolling

Button::new(volume_label).on_scroll(|cx, steps| cx.audio().change_volume(steps * 5))

on_scroll gets whole vertical steps as an i32, positive for up. A wheel notch is one step, and a touchpad gives one per 15 pixels.

on_wheel gets every scroll event as a Wheel, with an x and a y axis, each holding pixels, notches and stop, plus a source of ScrollSource::Wheel, Finger, Continuous or WheelTilt. Here positive is down and right. 

Button::new(timeline).on_wheel(move |_cx, wheel| {
  offset.update(|x| *x += wheel.x.pixels + wheel.y.pixels);
})

A button with either handler takes the scroll from a scroll view around it.

Drags

Button::new(knob).on_drag(move |_cx, drag| match drag.phase {
  DragPhase::Start => grabbed.set(true),
  DragPhase::Move => x.set(drag.position.x),
  DragPhase::End => grabbed.set(false),
})

A Drag has the phase, the start and the position in the button's own coordinates, and the button's size. A drag starts once the held pointer has moved 10 pixels, or at the press on a button with no click handler. It ends on release or when the pointer leaves the window. For a value on a track, use a Slider.

Drag and drop

One button carries a value of any Clone type, and another takes it. 

// A workspace button that takes windows dropped on it.
Button::new(Text::new(move || ws.get().name))
  .on_drop(move |cx, window_id: u64| move_window(cx, window_id, &ws.get().name))
  .drop_hovered(over)
  .style(move || if over.get() { WS_TARGET } else { WS })

// A window thumbnail that can be dragged.
Button::new(thumbnail).drag_data(move || Some(window.get().id))
Method What it does
drag_data(data) An Option<T>. While it holds a value, the button drags and carries it. While None, it clicks as usual. As a closure it can follow an edit mode.
on_drop(handler) Takes drops of the handler's value type. It gets &Cx and a copy of the value.
drop_hovered(signal) True while a drag this button would take is over it.

The source's own on_drag sees drag.dropped at DragPhase::End. A drag reaches buttons in all the shell's windows. displaced slides a reordered list into place.

To drag to and from other programs, use DragContent, text or file URIs: 

// Drag a wallpaper into a file manager or a terminal.
Button::new(thumb).drag_content(move || {
  Some(DragContent::Uris(vec![format!("file://{}", path.display())]))
})

// Take files dropped from a file manager.
Button::new(Text::new("Drop here"))
  .on_drop_content(move |_cx, content| {
    if let DragContent::Uris(uris) = content {
      dropped.set(uris);
    }
  })

Turning a button off

enabled(false) stops every handler and state style, and lets the pointer through to a button around it. It shows nothing for being off, so dim it yourself. 

Button::new(Text::new("Connect"))
  .enabled(move || !busy.get())
  .style(move || if busy.get() { BUTTON.opacity(0.4) } else { BUTTON })

Keyboard focus

A window gets keys only with a keyboard_focus of Exclusive or OnDemand, or as a floating window. Inside it, one button or text field has the focus.

  • Tab and Shift+Tab move it, in the order the widgets were added. Tab also stops on each link of a Text with an on_link, and Enter or Space opens it. In a TextArea Tab types a tab, so Ctrl+Tab moves on.
  • A click focuses a text field, but not a button.
  • focus(true) on a Button or a TextInput takes it whenever the value turns true.
  • Enter or Space clicks the focused button, and focus_style shows which one that is.

Keys

A key press goes to the focused text field, then the focused button's on_key, then the window's on_key. A handler returns true if it used the key. 

PanelWindow::new(output)
  .keyboard_focus(KeyboardFocus::Exclusive)
  .on_key(move |_cx, event| {
    match event.key {
      Key::Escape => open.set(false),
      Key::Down => picked.update(|n| *n += 1),
      Key::Up => picked.update(|n| *n = n.saturating_sub(1)),
      Key::Character('q') if event.modifiers.ctrl => open.set(false),
      _ => return false,
    }
    true
  })
KeyEvent field What it holds
key A Key: Enter, Escape, Tab, Backspace, Delete, Left, Right, Up, Down, Home, End, PageUp, PageDown, Function(n), Character(c) or Other(keysym).
text The text the key types, if any.
modifiers ctrl, alt, shift and logo, each a bool.
repeat Whether the key is being held.

For a key that works while no shell window has the focus, bind it in the compositor to crabshell ipc, or on Hyprland use a global shortcut.

Text fields

A launcher is a TextInput that owns the keyboard, a memo that filters by its text, and a window handler for the keys the field passes on. 

let query = cx.signal(String::new());
let picked = cx.signal(0_usize);
let shown = cx.memo(move || {
  let query = query.get().to_lowercase();
  apps.iter().filter(|app| app.contains(&query)).cloned().collect::<Vec<_>>()
});

PanelWindow::new(output)
  .layer(Layer::Overlay)
  .keyboard_focus(KeyboardFocus::Exclusive)
  .on_key(move |_cx, event| {
    let count = shown.with(Vec::len);
    match event.key {
      Key::Down if picked.get_untracked() + 1 < count => picked.update(|n| *n += 1),
      Key::Up if picked.get_untracked() > 0 => picked.update(|n| *n -= 1),
      Key::Up | Key::Down => {}
      _ => return false,
    }
    true
  })
  .child(
    TextInput::new(query)
      .placeholder("search")
      .focus(true)
      .on_accept(move |_cx, _text| launch()),
  )
