a desktop shell you write in rust.

crabshell is a rust replacement for quickshell. your bar, its popups and, later, everything else quickshell does live in one rust crate. save it, and crabshell rebuilds it and swaps the running shell in about a second.

measured in phase 0, on 10 nov 2026. the full v0.1 bar, with workspaces, the tray, volume and a clock, uses 18.7 MiB (15% of quickshell's 125.2 MiB) and draws its first frame in 11 ms on headless sway. quickshell drew on the gpu through opengl, its default.

where crabshell is ahead

  • one bad binding stays contained. a panic in a config closure is logged with its widget path, that binding turns off, and the rest of the shell keeps running.
  • crashes recover on their own. a dead shell is back in about a second, and three quick crashes fall back to the last build that worked.
  • mistakes show up before the shell runs. the compiler checks every config, and rust-analyzer gives completion and inline errors.
  • idle means asleep. a bar with a minute clock wakes once a minute and does nothing in between. every test suite checks it.
  • a broken edit keeps your bar up. the old shell stays on screen, and a notification shows the first compiler error.

where crabshell is behind

  • configs have to compile. quickshell reloads qml without a build. here the first build takes minutes, and each edit rebuilds: 0.7 s for a one-line change to the template.
  • every user needs a rust toolchain, and writing a config means learning closures and move.
  • a reload restarts the shell. the bar is gone for 13 to 19 ms, and every color change is a rebuild.
  • hyprland is checked against a stand-in. its workspaces, monitors and windows follow a fake hyprland in the tests, and its focus grab and global shortcuts haven't run on hyprland yet. niri gets only the generic protocols.
  • blur is the compositor's. a window asks for it through ext-background-effect-v1, which sway doesn't have. text uses grayscale antialiasing, where qt uses subpixel.
  • most of quickshell isn't built yet, and there are no configs to copy from.

where it stands

v0.1 was the first release, and v0.2 on crates.io adds phases 7 to 12: floating windows, keyboard and text input with input methods and the clipboard, scrolling lists, images and clipping; animations that run only while something moves, style fades, gradients, shadows and blur behind windows; desktop services: the battery and power profile, bluetooth, networks, media players, every audio device, a notification server and an idle monitor; and system integration: your installed apps, programs, files, json files and sockets, an ipc handler for the command line, every window, a screen's or window's picture, and a wallpaper's colors; and a lock screen that checks your password with pam, a greetd greeter and a polkit agent; and more compositors: hyprland's workspaces, monitors and windows, i3's events and outputs, the generic workspace protocol, global shortcuts, a focus grab and the shortcut inhibitor. v0.3 adds phase 13, a check against every quickshell type. the roadmap has every phase.
