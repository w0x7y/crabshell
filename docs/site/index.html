crabshell Docs

Your desktop shell is a Rust crate.

A toolkit for the bars, launchers, lock screens and notifications of a Wayland desktop. crabshell run rebuilds your shell and swaps it in on each save. 

$ cargo install --locked crabshell-cli

Get started See the examples

Light, and asleep when idle

Stop for three seconds and the crab goes in, and this page stops with it: it asks for no frame, runs no animation and holds no timer. A shell built with Crabshell idles the same way. Here it is beside Quickshell, each drawing the same bar.

What you get, and what it asks

One crate and one use crabshell::prelude::*. A part you never call never starts.

In the toolkit

  • Windows Panels, floating windows, popups and lock surfaces
  • Widgets Buttons, text, sliders, lists and a canvas
  • Signals Closures that run again when state changes
  • Styles Gradients, shadows, masks and fades
  • Motion Timers, transitions and springs
  • Drawing Paths, icons, image filters and wallpapers
  • Services The tray, audio, networks, batteries and notifications
  • Compositors Sway, Hyprland and niri workspaces, and other windows
  • Logins A session lock, a greeter and a polkit agent

What it asks of you

  • 1.0 s to see an edit Each save is a cargo build and a restart. A config's first build takes a few minutes.
  • Rust as the config language You need a toolchain and you write closures. The compiler catches a mistake before the shell runs.

Run your first bar

You need Rust 1.99 or newer, a compositor with layer-shell and four system libraries. The install guide lists them. 

  1. $ cargo install --locked crabshell-cli

    Installs the crabshell command.

  2. $ crabshell init

    Writes a Cargo project to ~/.config/crabshell.

  3. $ crabshell run

    Builds it and puts a bar on every monitor. Each save of src/main.rs swaps it.
