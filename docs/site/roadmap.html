roadmap

fourteen phases. a phase is done only when its exit check passes. phases 0 to 6 reach v0.1, a bar for sway. phases 7 to 13 bring the rest of quickshell.

to v0.1
to everything quickshell does
green check: done
yellow bar: partly done
empty box: not done yet
red cross: tried, and it failed. nothing has so far

    decisions still open

    • which other wlroots compositors to test (river, labwc, wayfire), and which of them implement ext-workspace-v1.
    • whether a reload should start the new shell before stopping the old one, to remove the blink. both bars would reserve space for a moment.
    • whether to stay on libpulse after v0.1, or move to native pipewire.
    • when to add hyprland and niri, and in which order.
    • whether the shell should exit with status 1 when every monitor's builder panics at startup, so the fallback to the last good build can fire.

    each phase's exit check and results are in the design doc.
